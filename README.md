## Featured project · PhoneDesk

**Your Android phone. Your Windows desktop. Fewer commands to remember.**

A local Windows app built around scrcpy, with camera controls, screen mirroring, and USB-to-Wi-Fi setup in one interface.

| Camera controls | Screen mirroring | Flexible connection |
| :--- | :--- | :--- |
| Choose cameras and adjust quality, rotation, and supported controls. | View and control your Android screen from Windows. | Start with USB; switch to Wi-Fi after setup. |

**Windows x64 · Android 12+ · V1.1 beta · MIT-licensed PhoneDesk code**
